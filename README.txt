POLYNUMB WEBSITE

FONT
The POLYNUMB wordmark uses the same CSS treatment as the previous DRIFTLAB text: Arial Black / Arial, bold italic, with a skew. The reference logo itself looks like a custom motorsport-style wordmark rather than a normal stock font.

PROJECT IMAGES
Recommended: 1600 x 900 px (16:9). 1920 x 1080 px also works very well.
The CSS uses object-fit: cover, so images are never stretched. Images with another aspect ratio will crop at the edges instead.

To replace a placeholder:
<div class="project-image">
  <img src="images/poly-drifters.jpg" alt="Poly Drifters">
</div>

Create an images folder beside index.html.
